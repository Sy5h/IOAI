# 검증한 범위와 남은 한계

검증일: 2026-10-16. [공식 공개 데이터 실측](benchmark.ko.md)에 여섯 문제의 점수·실행 시간·개선 전후 결과를 정리했다. 이 문서는 코드와 제출 포장의 검사 범위를 설명한다. 단위 테스트 통과와 실제 문제 점수를 구분한다.

최종 소스에서 **47개 테스트가 11.334초에 통과**했고, 여섯 노트북의 소스 일치 검사와 전체 Python 문법 검사를 통과했다.

## 검사 명령

```bash
python tools/build_notebooks.py
python -m unittest discover -s tests -v
python tools/build_notebooks.py --check
python -m compileall -q solutions tools tests benchmarks
```

| 범위 | 확인한 내용 |
|---|---|
| Find the Order / Robot Chasing | rank 역순열, prefix 유지, 순열 유효성, 화자 제약 fallback, Qwen target-token mask, 명령 파싱, 막힌 이동의 방향 의미, 행 순서, 작은 학습 실행, 트리용 특징, 이미 저장한 예측의 보존 |
| Double Agent Dilemma / IOAI Field | 두 모델 공격·축소, clipping 입력 동등성, 실패/시간 초과 영텐서, 작은 학습률 실패 후 재시도·시간 예약, ZIP 텐서 크기, dropout 범위·평가식, 파라미터 수, hard routing, affine fit, 복수 config |
| Potato / Ghost | 관측 방향·동점·게임 reset, 초기 두 단어 후보 유지, 작은 게임 시뮬레이션, 원문 offset, 글 단위 holdout, 단일 경계, 문장 구분점 없는 글, 시간 부족 fallback, 통제된 임베딩 통합 검사 |
| 노트북 포장 | Python 소스 일치, 문법, 파일 크기, 실행 한 번, Potato의 Jupyter/nbconvert 분기, Field 보조 파일 일치 |

## 실제 실행과 합성 검사의 구분

실측은 공식 데이터와 허용된 실제 모델을 사용한다. Order·Robot·Potato·Ghost는 원본 채점식을 검토한 로컬 실행기에서 평가한다. Dilemma와 Field는 공식 평가 함수를 직접 호출한다. 원래 대회의 Podman 컨테이너, 자원 계측, 전체 제출 검증 절차까지 같은 환경으로 복제한 것은 아니다.

일반 평가용 정답은 풀이 프로세스에 인자로 넘기지 않는다. 파일을 분리한 연구용 실행이며 OS 보안 격리를 주장하지 않는다. 제출용 코드·노트북은 평가 정답이나 Potato의 심판용 비공개 임베딩을 읽지 않는다. **Dilemma의 이미지 라벨은 예외로, 문제에서 허용한 공격 목표이므로 풀이가 읽는다.**

공개 평가 자료를 보고 기본값을 유지하거나 후보를 버린 경우에는 그 판단 과정을 결과 JSON에 명시했다. 그런 최종 선택까지 완전히 미지의 데이터에서 검증했다고 주장하지 않는다. 이 저장소 코드의 최적성이나 새로운 비공개 데이터의 점수를 보장하지 않는다.

## 제출 포장과 예외 처리

Ghost는 중간 문장 구분점이 없는 글에서도 가능한 경우 양쪽 최소 180단어 조건을 만족하는 원문의 단어 시작 위치를 사용한다. 일반 추론과 시간 부족 fallback을 회귀 테스트로 확인했다.

Robot은 로봇별 학습을 진행하면서 예측을 저장한다. 뒤의 로봇 처리에서 예외가 발생해도 이미 계산한 부분을 최빈 행동으로 덮어쓰지 않도록 수정했다. 기록된 정상 종료 실측에는 이 예외 경로가 사용되지 않았다.

노트북 생성기는 Python 파일의 최상위 `__main__` 실행부를 제거한 뒤 실행 셀을 한 번만 넣는다. 소스 파일과 노트북의 내용이 다르면 `--check`가 실패한다. Field 제출 모델은 공식 grader가 요구하는 `custom_model` 모듈 이름으로 저장한다.

## Field 모델 제약

현재 모델은 **17,424개 파라미터**이며 등록 buffer가 없다. 마지막 I의 dropout 출력은 -1920부터 1920까지 16개 값이다. 합성 좌표 5,000개에 각 10회 출력하여 공식 표준편차 식으로 확인한 영역 점수는 1.0이었다. 이 부분 검사와 별도로, 공식 Linux CPython 3.13 보호 런타임에서 public·A·B 설정을 재학습하고 전체 점수를 측정했다.

단일 공개 설정의 결과만으로 복수 설정에서 같은 성능·시간이 나온다고 주장하지 않는다. 코드의 복수 config 저장·분배는 합성 검사로 확인했으며, 이번 공식 공개 A/B 파일은 각각 단일 설정이었다.

## 남은 한계

- 표의 점수·시간은 각 항목 한 번씩 측정했다. Ghost 원본 B의 추가 안정성 확인은 별도 기록했다. 반복 측정 평균이나 신뢰구간은 아니다.
- 다른 GPU·CPU, 패키지 조합, 원래 대회 환경에서는 점수와 실행 시간이 달라질 수 있다.
- 소프트 타이머는 진행 중인 긴 단일 연산이나 프로세스 초기화를 강제 중단하지 않는다.
- Ghost의 후보 실행 중 Windows native 오류가 두 번 발생했다. 길이순 배치를 제거한 실행에서도 재발해 원인을 특정할 수 없었다. 길이순 배치와 후보 설정은 채택하지 않았으며 성공·실패 기록을 모두 보존했다.
- 문제의 공개 데이터·허용 모델·실행 환경이 필요하며, 이 저장소는 이를 재배포하지 않는다.

패키지 버전, 모델 revision, 데이터 규모, 명령과 실패 기록은 [실측 원자료](../benchmarks/)에 보존했다.
